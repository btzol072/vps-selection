## 选建站 VPS 之前，先回答三个问题

访客位置决定线路和机房，流量决定套餐档位，要不要备案直接决定机房能不能选国内。这三个问题想清楚了，几十行的价格表就只剩两三行和你有关。

### 访客在哪：线路比距离更值得纠结

同样是美国机房，线路的差距能比物理距离大得多。面向国内访客时，常见线路从优到劣大致是：电信 CN2 GIA、联通 AS9929、联通 AS4837、电信 CN2 GT。CN2 GIA 是电信 CN2 网络里规格最高的一档，回程全程走优质骨干，晚高峰也相对稳；CN2 GT 名字里也有 CN2，部分路段仍会绕普通骨干，高峰期差距就出来了。当然，同一条线路在不同省份、不同运营商那里的表现不完全一样，下单前找商家提供的测试 IP，用你自己的网络实测最靠谱。

机房位置的大原则：国内机房延迟最低，但要备案；其次是中国香港、台湾和日本、韩国、新加坡这些周边节点；美国机房距离最远，必须靠 CN2 GIA 这类优质线路把体验拉回来。

### 流量怎么算：1Mbps 和 500GB 分别意味着什么

很多便宜套餐写着“1Mbps 不限流量”，先算一笔账再心动。1Mbps 的实际下载速度约 128KB/s，访客第一次打开一个 1MB 的网页要等 8 秒左右，图片多的首页更久。海外 VPS 正相反：端口带宽普遍是 Gbps 起步，流量有总量上限。以 500GB 月流量为例，按单个页面 1MB 粗算，一个月大约能承载 50 万次页面访问，个人博客和小型企业站几乎用不完；图片站、提供下载的站点就得重新算。

所以别只盯着“不限流量”四个字，先估自己的页面体积和日均访问量，再决定要大带宽小流量，还是小带宽大流量。

### 虚拟化与配置：KVM 优先，小配置起步

同一价位优先选 KVM，其次 Xen，最后才是 OpenVZ，这个排序同时也是三类技术价格从高到低的排序。KVM 是完整虚拟化，可以自己换内核、跑 Docker，出问题时排查余地大。

配置方面有个容易被忽视的点：对多数网站来说，把硬盘换成 SSD/NVMe 带来的提升，比多加一倍内存更明显。跑 WordPress 或静态博客，1GB 内存起步够用，2GB 更从容。拿不准就从小套餐开始，多数商家支持后期升配，比一开始为用不上的配置付费划算。

## 从下单到上线：建站前后要注意的几件事

VPS 买回来只是开始，下面这几件事决定了后面省不省心。

1. **备份别只靠快照。** 任何 VPS 都有挂掉的可能，商家提供的快照功能要用上，但数据库和网站文件还要定期导出到站外。真出事的时候，一份站外备份能把损失控制到最小。
2. **看清流量超额怎么计费。** 标价 $5 的套餐，如果超出流量上限按量计费，账单可能远超套餐本身。下单前看一眼超额单价，或者干脆选流量余量大的档位。
3. **机房选离访客近的。** 你自己 ping 得快没有意义，延迟要看访客那一端。面向国内就测 CN2 GIA 节点的晚高峰速度，面向欧洲就直接选欧洲机房。
4. **域名和 CDN 可以分开解决。** 域名在 Cloudflare、Porkbun、Namecheap 这类注册商注册，.com 的续费价大多在 $10–11/年；CDN 用 Cloudflare 免费版就能起步，自带 SSL 证书和基础防护。面向国内的站点，常见组合是 CN2 GIA 线路的 VPS 加 Cloudflare 免费 CDN，域名解析也可以直接放在 Cloudflare。

## 建站 VPS 常见问题

### 建站 VPS 最低需要什么配置？

1GB 内存、20GB SSD 是能正常跑起来的底线，适合轻量博客和小型展示站，重点把硬盘选成 SSD 或 NVMe。流量按“单页体积 × 月页面访问量”估算，多数个人站 500GB/月 用不完。

### 用境外 VPS 建站需要备案吗？

只有服务器位于中国大陆才需要 ICP 备案，香港、美国等境外机房都不需要。不备案的代价是速度完全取决于线路质量，这就是 CN2 GIA 这类优化线路存在的原因。

### 先月付还是直接年付？

确认线路质量之前先月付，晚高峰测速稳定一到两个月再转年付；年付单价通常更低，适合已经确定长期使用的方案。

### IP 出问题或商家跑路了怎么办？

定时备份是最可靠的保险，重要数据每周导出站外一次。优先选自助换机房这类功能齐全的商家，IP 异常时自己迁移就能换到新 IP，不用排队等工单。
